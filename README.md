# COS314-Pathfinding-DFS-BFS-Astar
A comparative analysis of Depth-First Search (DFS), Breadth-First Search (BFS),  and A* Search algorithms navigating a 100x100 grid with a U-shaped obstacle  (concave trap) and 15% random noise. Implements Manhattan distance heuristic  for A* and evaluates algorithm performance based on path cost, nodes visited,  execution time, and optimality.
